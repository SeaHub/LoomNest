# LoomNest 顶部导航合并设计

## 目标

移除截图红框标出的品牌副标题、`Notes` 导航入口和作品区操作提示，并把作品分类筛选直接并入顶部主导航。合并后减少页面层级和重复占用的垂直空间，同时保留现有筛选能力与视觉反馈。

## 顶部结构

桌面端顶部栏按以下顺序排列：

1. `LoomNest` 品牌；
2. 作品分类筛选：`全部 / 网站 / 小程序 / 应用 / 未来作品`；
3. `Works` 主导航入口；
4. 主题切换按钮。

品牌后的 `— Selected Works 2022—∞` 文案删除。`Notes` 入口删除，`Works` 继续指向 `#works`，主题切换保持现有行为。

分类筛选直接使用顶部玻璃栏作为容器，不再保留原筛选栏的独立玻璃外框，避免出现嵌套玻璃层。每个分类继续显示作品数量；当前分类使用现有的高亮胶囊样式，悬停、键盘焦点和按下反馈保持可见。

## 主内容区

作品区保留 `ARCHIVE / 01—∞`、`Selected Works`、列表表头、作品行、展开详情、加载状态和空状态。

以下内容从主内容区删除：

- 独立的分类筛选栏；
- “点击作品行，展开详情”提示。

标题区域在删除提示后只保留左侧标题内容。标题与列表之间使用正常间距衔接，不留下原筛选栏占用的空白。

## 响应式布局

桌面端顶部栏保持单行。分类筛选占据品牌与右侧操作之间的弹性空间；当宽度收窄时，分类区域允许横向滚动，不挤压品牌、`Works` 和主题切换。

移动端顶部栏使用两行：

- 第一行：`LoomNest` 与主题切换；
- 第二行：`Works` 和全部分类筛选按钮。

第二行位于同一个顶部玻璃栏内并支持横向滚动。滚动条不作为主要视觉元素，但触控、触控板和键盘仍可操作。分类按钮保持单行，不换行，也不改为下拉菜单。

## 行为与数据

- 继续使用现有 `activeFilter`、`handleFilter` 和 `countFor`，不改变作品数据格式。
- 选择分类后仍关闭已展开的作品详情，并把焦点移到所选分类按钮。
- 作品列表筛选动画、展开/收起、Escape 收起、主题切换和减少动态效果支持保持不变。
- 不新增页面、路由、依赖或后端能力。

## 无障碍

- 分类控件继续使用带名称的工具栏语义和 `aria-pressed`。
- `Works` 锚点与跳到作品列表的 skip link 继续指向有效的 `#works`。
- 删除 `Notes` 后不保留无目标或重复入口。
- 横向滚动区域不得裁掉键盘焦点轮廓；所有按钮保持可见焦点态。

## 验证

自动化检查应确认：

- 品牌副标题、`Notes` 和操作提示不再出现在模板中；
- 分类工具栏位于顶部栏内，主内容区不再包含第二份筛选栏；
- `Works`、主题切换、分类按钮及其现有事件绑定仍存在；
- 现有单元测试和生产构建通过。

浏览器检查至少覆盖：

- 桌面端顶部栏顺序正确、没有嵌套玻璃外框，各区域不重叠；
- 主内容标题下直接衔接作品表格，没有原筛选栏遗留空白；
- 每个分类可正确筛选、显示数量并更新选中态；
- 移动端顶部栏为两行，第二行可横向滚动，页面无横向溢出；
- 浅色、深色、键盘焦点、作品展开和 Escape 收起仍正常。
