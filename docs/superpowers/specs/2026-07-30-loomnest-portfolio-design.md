# LoomNest 作品集网站交互设计规格

## 目标

LoomNest 是一个长期累积个人网站、小程序、移动应用及未来数字作品的作品集。访客应能快速扫描作品、理解作品类型，并在同一位置完成访问网站、扫码体验小程序或前往应用商店下载。作品原型与正式工程解耦：本次交付只用于验证信息架构与交互，不作为后续生产代码模板。

## 视觉方向

采用已选定的「Living Index · 动态索引」：理性网格、编号索引、矩形宣传图和展开式详情。视觉层使用 Apple Liquid Glass 取向，但控制材质范围：筛选栏、选中行、详情面板和入口按钮使用半透明材质、背景模糊、细内描边与柔和高光；普通作品行保持轻量分隔，避免整页卡片化。

主题支持 `system`、`light`、`dark` 三态。默认跟随 `prefers-color-scheme`，右上角提供手动切换。浅色使用雾灰底与黑色文字，深色使用深蓝黑底与半透明白色表面；橙色用于主要行动，蓝紫用于选中态与辅助高光。所有文字和操作保持可读对比度。

## 页面与交互

原型为单路由作品索引页：桌面端左侧固定简介，右侧为筛选与作品列表；小于约 900px 时改为单列，手机端筛选栏横向滚动。筛选项为「全部 / 网站 / 小程序 / 应用 / 未来作品」，显示实时数量。

每个作品行展示编号、宣传图、名称、类型、年份与访问方式。点击或键盘 Enter/Space 展开该行详情，并自动收起其他行。详情按 `type` 渲染入口：

- `web`：访问网站外链。
- `mini-program`：二维码、替代文本和扫码体验说明。
- `mobile`：App Store 与 Google Play 链接，只展示实际存在的平台。
- `future` 或 `status: "soon"`：显示 Coming Soon，不展示无效链接。

外链在新标签打开并带有明确的无障碍名称；Escape 可收起当前详情。主题切换、筛选、展开和链接均有可见焦点态，并尊重减少动态效果设置。

## JSON 配置契约

作品存放于独立的 `works.json`，字段保持扁平、可快速编辑：

```json
{
  "id": "flow-diary",
  "title": "Flow 日记",
  "titleEn": "Flow Diary",
  "type": "mobile",
  "year": 2026,
  "summary": "专注与记录的日常伴侣",
  "image": "./assets/flow-diary.jpg",
  "role": ["产品设计", "交互设计", "开发"],
  "access": {
    "appStore": "https://apps.apple.com/...",
    "googlePlay": "https://play.google.com/..."
  },
  "status": "live"
}
```

页面加载 JSON 后按 `type` 生成入口，按配置顺序渲染。缺失链接时不渲染空按钮。JSON 加载或解析失败时展示友好提示并使用内置示例数据，保证原型仍可预览。

## 原型范围与验收标准

交付一个可在本地预览、也可放入 GitHub Pages 的静态 HTML 原型，配套独立 JSON 与演示宣传图/二维码素材。必须可切换主题、筛选类别、展开/收起作品，并能在三类作品上看到不同入口。必须在桌面与手机宽度下保持布局完整，键盘操作可用，且不依赖后端、登录、数据库或后台编辑能力。
