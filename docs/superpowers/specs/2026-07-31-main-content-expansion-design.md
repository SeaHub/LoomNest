# LoomNest 主内容扩展设计

## 目标

移除作品页左侧整块 LoomNest 简介，让作品列表占满现有内容容器，从而扩大主内容显示窗口。与该简介锚点绑定的顶部 `About` 导航同时移除，避免保留无效入口。

## 页面结构

- `src/App.vue` 删除 `intro-column` 及其中的标题、双语介绍和地点/方向/更新时间信息。
- 顶部导航保留 `Works` 与 `Notes`，删除指向 `#about` 的 `About`。
- `works-column` 继续位于 `page-grid` 内，并成为唯一主栏；现有筛选、列表、作品展开详情和加载/空状态结构保持不变。
- 页头、主内容和页脚继续共享当前最大宽度与响应式页边距，避免扩大内容时贴近视口边缘。

## 布局与响应式

桌面端把 `page-grid` 从双栏改为单栏，使作品区使用完整容器宽度。原有主内容顶部和底部留白保持一致，不额外增加替代介绍区。

移动端本来就使用单栏，因此只清理不再需要的左栏间距和样式，不改变作品行在窄屏下隐藏年份与访问预览的既有行为。

仅供简介栏使用的标题、正文、元数据和入场动画样式应一并删除；仍被作品区域使用的通用 `eyebrow` 与其他动画样式保留。

## 功能边界

- 不修改作品数据格式、内容和资源。
- 不修改筛选、作品展开/收起、访问链接、主题切换和减少动态效果支持。
- 不新增依赖，不改变部署方式。
- 不把被删除的简介内容迁移到其他位置。

## 无障碍与导航

- 跳到作品列表的 skip link 继续指向 `#works`。
- `Works` 和 `Notes` 锚点保持有效。
- 删除 `About` 后，主导航不包含无目标链接。
- 作品列表现有键盘操作、焦点态与 ARIA 属性保持不变。

## 验证

自动化检查应覆盖页面结构中不再出现 `intro-column`、`#about` 导航与简介文案，并确认 `works-column`、`Works`、`Notes` 仍存在。完成后运行现有测试和生产构建。

浏览器检查至少覆盖：

- 桌面端作品区占满主内容容器，没有遗留左栏或大块横向空白；
- 筛选栏、表头、作品行与展开详情随主栏一起变宽且对齐；
- 移动端作品列表紧接页面标题区，不产生来自已删除简介栏的额外空隙；
- 主题、筛选、作品展开、Escape 收起和页内导航仍正常。
