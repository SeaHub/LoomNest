# LoomNest 页头筛选左对齐设计

## 目标

把顶部分类筛选栏从页头中部左移到 `LoomNest` 品牌后的空白区域，并把作品区大标题从 `Selected Works` 改为 `Works`。其余布局、数据和交互保持不变。

## 页头布局

继续使用现有三列页头结构：

1. `LoomNest` 品牌；
2. 包含分类筛选和 `Works` 导航的弹性区域；
3. 主题切换按钮。

分类筛选容器从弹性区域内的居中对齐改为左对齐，使第一个筛选按钮紧接品牌后的现有网格间距，落在截图蓝框位置。`Works` 导航仍固定在弹性区域右侧，主题切换按钮位置不变。

不使用固定像素位移、负边距或 transform 模拟左移，避免不同桌面宽度下产生重叠。

## 作品标题

作品区继续保留 `ARCHIVE / 01—∞`。仅将 `#works-heading` 的文本从 `Selected Works` 改为 `Works`，字号、字重、间距和锚点保持不变。

## 响应式行为

- 桌面端分类筛选在品牌后左对齐，`Works` 与主题按钮保持右侧。
- 中间宽度继续允许分类容器内部横向滚动，不产生页面级横向溢出。
- 移动端继续使用现有两行页头：第一行品牌与主题，第二行 `Works` 和分类筛选。
- 不改变移动端分类按钮的横向滚动、选中态和焦点自动滚入视图行为。

## 功能边界

- 不修改 `filters`、`activeFilter`、数量统计或作品数据。
- 不修改筛选、作品展开/收起、Escape 收起、主题切换和减少动态效果支持。
- 不新增依赖、路由、资源或后端能力。
- 不调整作品表格、卡片或页脚。

## 验证

自动化验证应确认现有测试和生产构建通过。

ego-browser 验证至少覆盖：

- 桌面端筛选栏位于品牌后的左侧目标区域，不再居中；
- `Works` 导航与主题按钮仍位于右侧且不重叠；
- 大标题显示为 `Works`，`ARCHIVE / 01—∞` 保留；
- 700px 中间宽度和 390px 移动端无页面级横向溢出；
- 分类筛选、焦点滚动、作品展开/Escape 和主题切换正常；
- GitHub Pages 部署后的线上页面与本地实现一致。
