# LoomNest

Where Ideas Become Reality.

## Prototype

The interactive portfolio prototype lives in `prototype/`. Its work list is configured in [`prototype/works.json`](prototype/works.json); update that file to add or edit projects.

Preview it locally from the repository root:

```bash
python3 -m http.server 4173 --directory prototype
```

Then open `http://127.0.0.1:4173/`. The prototype is static and can be copied to a GitHub Pages root without a build step.
